# Modern Calculator

A modern and responsive calculator built using HTML, CSS, and JavaScript.

## Features

* Beautiful Glassmorphism UI
* Responsive Design
* Basic Arithmetic Operations
* Error Handling
* Hover Animations
* Clean and Modern Layout

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```bash
modern-calculator/
│
├── index.html
├── style.css
└── script.js
```
